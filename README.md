## 設計概念

整體走「**Z 世代國際派 ✕ 議事殿堂**」的編輯風格。

### 為什麼是這個風格？

- 候選人 **23 歲**（剛達民代年齡門檻），是真正的 00 後 Z 世代
- **縣議員層級**比其他四位（市民代表）高一階，需要更具份量的視覺
- 走過 **美國、中國、日本、泰國** 四國國際歷練
- 文化大學 **國際企業管理 + 政治學雙主修**
- 立法院法案助理實務經驗
- 家族企業是彰化在地知名品牌「**高北木瓜牛乳**」

### 配色策略：午夜藍 × 木瓜橘

- **主色：午夜藍（#0e1f3a）** ── 議會殿堂的莊重感、立法院藍
- **強調色：木瓜橘（#ed7d3a）** ── **致敬家族企業「高北木瓜牛乳」**，是專屬於蘇智弦的視覺記憶錨點
- **底色：暖米色（#f4ede0）** ── 平衡冷色系，傳達溫度與人情味

> 木瓜橘的選擇是有故事的：別人不會用這個顏色，但這顏色立刻把「高北木瓜牛乳」這個地方品牌跟候選人連結起來。

### 字體策略

- **中文標題**：Noto Serif TC 900（莊重、議事感）
- **西文展示字**：Manrope 800（國際派、現代設計感）
- **西文標籤字**：JetBrains Mono（程式碼字體、傳達理性與分析力）
- **中文內文**：Noto Sans TC（清楚易讀）

### 獨家設計亮點

1. **「跨越色彩 × 世代融合」雙主軸宣言（#manifesto）** ── 把候選人自述的核心理念做成首頁第二大區塊，雙柱式排版強化兩個關鍵概念。

2. **「國際視野時間軸」（#journey）** ── 五站式橫向時間軸：彰化高中 → 泰北 → 中國 → 美國 → 立法院。這是其他四位候選人完全沒有的維度。

3. **「三鄉鎮」獨立區塊（#district）** ── 把和美 / 線西 / 伸港三個鄉鎮各自的產業特色（住宅商圈 / 彰濱工業 / 海港農漁）視覺化成三張卡片。

4. **口號中的數學符號（× ＋）** ── 「選弦×與能、福利＋加乘」用數學符號做視覺強化，呼應候選人雙主修商學的邏輯背景。

5. **政見 6 條附帶英文 BADGE 標籤** ── PRIORITY、FAMILY、INDUSTRY、AGRI、CARE、LEGAL，把抽象政策轉化為標籤化、易記憶的關鍵字。

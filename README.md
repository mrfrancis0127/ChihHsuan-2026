## 🚀 快速開始

### 本地預覽
```bash
# 使用Python啟動本地伺服器
python3 -m http.server 8000

# 或使用Node.js
npx http-server

# 開啟瀏覽器訪問 http://localhost:8000
```

### GitHub Pages部署
1. 將檔案推送到GitHub倉庫
2. 在倉庫設定中啟用GitHub Pages
3. 選擇main分支作為部署來源
4. 網站自動發布至 `https://username.github.io/repo-name`
